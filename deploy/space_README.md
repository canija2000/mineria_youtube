# Mapa de YouTube

Mapa 3D explorable de ~35 mil videos de YouTube-8M, representados con EmbeddingGemma 2 a partir
de su texto y su miniatura. Se puede ubicar en el mapa un video, un concepto, una imagen o un canal.

Código y documentación: https://github.com/canija2000/mineria_youtube
